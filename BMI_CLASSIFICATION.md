### WHO BMI Classification
```
< 18.5          : Underweight
18.5 - 24.9     : Normal weight
25.0 - 29.9     : Overweight
30.0 - 34.9     : Obese Class I
35.0 - 39.9     : Obese Class II
>= 40.0         : Obese Class III
```

### Category, Advice, Risk Base on classification

#### Underweight
```
  advice = Increase caloric intake with nutritious foods.
  risk = Malnutrition, osteoporosis, weakened immunity.
```


#### Normal weight
```
  advice = Maintain current habits with balanced diet and exercise.
  risk = Low risk - keep it up!
```

#### Overweight
```
  advice = Reduce refined sugars and increase physical activity.
  risk = Elevated risk of diabetes and heart disease.
```

#### Obese (Class I)
```
  advice = Consult a healthcare provider for a weight-loss plan.
  risk = High risk of hypertension, diabetes, sleep apnea.
```


#### Obese (Class II)
```
  advice = Medical supervision strongly recommended.
  risk = Very high cardiovascular and metabolic risk.
```


#### Obese (Class III)
```
  advice = Seek immediate medical guidance.
  risk = Severe risk - life-threatening complications possible.
```
